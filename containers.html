HTML Containers

Container

Any element with an opening and closing tag that holds content.

<div>

Generic block container with no meaning of its own. This tag is useless without a class or id attribute.

<span>

Generic inline container with no meaning of its own.

Block vs Inline

A block container (element) - starts on new line and stretches across its parent container's full width. An Inline container (element) - stays in the flow of the line and takes only as much room as its content.

Symantic Elements

<article> Element - this contains content that can stand alone outside of the context of the current web page.

<aside> Element - this contains content that relates to the current web page indirectly, but is not part of the main content. An example of an aside would be an advertising link on a website, which is often created in a section off the right-side of a page. Weather
