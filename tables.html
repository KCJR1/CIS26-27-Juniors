HTML Tables

The Table Element

<table> - This is the element that creates an HTML table. NOTE: HTML tables are used to organized data into rows and columns.

Cell

Cell - it is location in the table at a specific row and column. Cells are created at the intersection of a row and a column.

Table Row

<tr> - an element that creates a row in a table. Table rows are Nested inside of Table elments.

Table Header

<th> - the element that creates a cell containing table header information about the data contained in a specific column.

Data Cell/Table Data

<table> - the element that creates a table cell containing table data.

Caption

<caption> - this element defines a short descritive text for the table.

Accessible Tables

Accessiblity refers to the ability of your web content to be consumed by people with disabilities. Here is an example of an Accessible Table:

In the following table we use the scope attribute to provide accessibility detail. the scope attribute is commonly assigned "col" or "row" to indicate if the table header applies to a column or row of data.

Colspan attribute/Rowspan attribute - a single table cell occupies a single row and column by default. But a cell may span multiple columns or multiple rows useing the colspan and rowspan attributes to specify how many columns or rows to spawn.
